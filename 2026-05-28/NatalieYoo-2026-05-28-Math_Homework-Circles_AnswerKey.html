Part D · Area ($A = \pi r^2$)
Problem 10
$r = 4$ cm. Find $A$, $\pi = 3.14$.
A = πr²
Square first: $r^2 = 4^2 = 16$
$A = \pi r^2 = 3.14 \times 16 = 50.24$
$A = 50.24$ cm$^2$
Problem 11
$D = 20$ ft. Find $r$ then $A$, $\pi = 3.14$.
r = D/2A = πr²
$r = \dfrac{20}{2} = 10$
$r^2 = 10^2 = 100$
$A = 3.14 \times 100 = 314$
$A = 314$ ft$^2$
Problem 12
$r = 7$ cm. Find $A$ using $\pi = \frac{22}{7}$.
A = πr²π = 22/7
$A = \dfrac{22}{7} \times 7^2 = \dfrac{22}{7} \times 49$
$= 22 \times \dfrac{49}{7} = 22 \times 7 = 154$  (the 7 cancels!)
$A = 154$ cm$^2$
Problem 13
$D = 28$ m. Find $r$ then $A$ using $\pi = \frac{22}{7}$.
r = D/2π = 22/7
$r = \dfrac{28}{2} = 14$
$A = \dfrac{22}{7} \times 14^2 = \dfrac{22}{7} \times 196 = 22 \times 28 = 616$
$A = 616$ m$^2$
Part E · Half & Quarter Circles
Problem 14
Half circle, $r = 6$ cm. Find the area, $\pi = 3.14$.
A = πr²half = ½
Full circle: $A = 3.14 \times 6^2 = 3.14 \times 36 = 113.04$
Half of it: $\dfrac{113.04}{2} = 56.52$
$A = 56.52$ cm$^2$
Problem 15
Quarter circle, $r = 10$ in. Find the area, $\pi = 3.14$.
A = πr²quarter = ¼
Full circle: $A = 3.14 \times 10^2 = 314$
Quarter of it: $\dfrac{314}{4} = 78.5$
$A = 78.5$ in$^2$
Part F · Explain in Words
Problem 16
Garden circumference $C = 6.28$ m. (a) explain & find $r$; (b) find area; (c) bonus: double the radius.
C = 2πrA = πr²reasoning
(a) Since $C = 2\pi r$, I can undo it: divide the circumference by $2\pi$ to get the radius. $r = \dfrac{C}{2\pi} = \dfrac{6.28}{2 \times 3.14} = \dfrac{6.28}{6.28} = 1$. So $r = 1$ m.
(b) $A = \pi r^2 = 3.14 \times 1^2 = 3.14$ m$^2$.
(c) In words first: Circumference grows in a "fair" way — it is a length, so doubling the radius simply doubles the distance around. Area is different because it fills a 2-D space (length × width feel), so doubling the radius makes it four times as big.
Check: New $r = 2$. New $C = 2\pi(2) = 4\pi = 12.56$ m → that is $2\times$ the old $6.28$. ✓   New $A = \pi(2)^2 = 4\pi = 12.56$ m$^2$ → that is $4\times$ the old $3.14$. ✓
$r = 1$ m,   $A = 3.14$ m$^2$;   double $r$ → $C \times 2$,   $A \times 4$
